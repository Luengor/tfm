\subsubsection{Ingesta y generación de \textit{embeddings}}
% Apertura de la imagen, segmentación (opcional), recorte de cada
% \textit{bounding box}, generación del \textit{embedding} por recorte y
% persistencia en el almacenamiento elegido.

\subsubsection{Recuperación, reducción y agrupamiento}
% Carga de todos los \textit{embeddings} desde el almacenamiento, aplicación
% de la reducción de dimensionalidad si procede, ejecución del algoritmo
% de \textit{clustering} y reconstrucción del mapeo clúster $\rightarrow$
% imágenes.

\subsection{Procedimiento experimental}
\label{subsec:experimental}
% Núcleo metodológico del trabajo: cómo se ejecutan y miden los

\subsubsection{Definición del espacio de configuraciones}
% Ficheros de \textit{configuration} en JSON declarando cada ejecución como
% combinación de \texttt{storage}, \texttt{embedding}, \texttt{segmenter},
% \texttt{reduction} y \texttt{clustering}. Generación automática por
% producto cartesiano a partir de una rejilla.

\subsubsection{Reutilización de almacenamientos}
% Estrategia para evitar repetir la ingesta cuando varias configuraciones
% comparten \texttt{storage + embedding + limit}: reuso de
% \texttt{db\_path}, \texttt{clear\_storage: false} y persistencia de las
% métricas de ingesta en la tabla \texttt{metadata}.

\subsubsection{Instrumentación y medición de tiempos}
% Etapas perfiladas por el \textit{runner}: \textit{setup}, limpieza,
% ingesta, reducción, \textit{clustering} y búsqueda por similitud.
% Forma exacta de cronometrar cada una.

\subsubsection{Selección automática de hiperparámetros}
% Cuando el usuario no fija ciertos parámetros, el sistema los estima:
% método del codo sobre la inercia (K-Means), minimización del BIC (GMM)
% y curva de k-distancias (DBSCAN).

\subsubsection{Cálculo de métricas de calidad}
% \textit{Silhouette} y Calinski-Harabasz calculadas sobre los
% \textit{embeddings} originales (sin reducir) para que la distorsión de
% la proyección no contamine la comparación entre configuraciones.

\subsubsection{Salida y agregación de resultados}
% Generación de ficheros CSV y JSON por lote de \textit{benchmark},
